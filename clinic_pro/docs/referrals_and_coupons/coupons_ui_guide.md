## 2. قائمة اختيار الكوبون المتاح (`AvailableCouponsBottomSheet`)

### الاستخدام والشروط (Conditional Visibility & Interactions):
1. عند فتح شاشة الدفع أو الاشتراك، يتم استدعاء دالة `get_available_coupons_for_owner(Owner_ID)`.
2. **إذا كانت القائمة فارغة (`coupons.isEmpty`)**:
   - لا يظهر زر "عرض الكوبونات المتاحة"، ويبقى فقط حقل الإدخال اليدوي.
3. **إذا وجد كوبونات صالحة وغير مستخدمة (`coupons.isNotEmpty`)**:
   - يظهر زر مع بادج بالعدد: `🏷️ لديك (X) كوبون متاح للاستخدام`.
   - بالضغط عليه، يفتح الـ `BottomSheet` ليعرض الكوبونات (العامة للحملات أو الخاصة الناتجة عن مكافآت الإحالة).
   - لكل كوبون زر **[تطبيق]** يملأ الكود تلقائياً ويقوم بحساب الخصم فوراً بالسيرفر.

```
┌────────────────────────────────────────────────────────┐
│  🎟️ الكوبونات المتاحة لك                                │
├────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────┐  │
│  │ 🎁 REF-25-A1B2                                   │  │
│  │ خصم 25% - مكافأة دعوة 3 أطباء                   │  │
│  │ ينتهي في: 31 ديسمبر 2026          [   تطبيق   ]   │  │
```

## 3. حالات التحقق والتنبيهات (Feedback & Validation States)

- **كوبون صالح ومطبق:** ظهور رسالة نجاح خضراء مع توضيح قيمة التوفير وتحديث السعر الإجمالي فوراً.
- **كوبون منتهي أو مستخدم مسبقاً:** إظهار رسالة خطأ باللون الأحمر تحت حقل الإدخال توضح السبب المرتجع من السيرفر.
- **كوبون غير مخصص لهذا الطبيب:** تنبيه بأن الكوبون مخصص لحساب آخر.
