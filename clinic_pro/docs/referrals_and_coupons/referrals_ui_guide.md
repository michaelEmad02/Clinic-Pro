## 2. نافذة إدخال كود الدعوة الذكية (`EnterReferralCodeBottomSheet`)

### الاستخدام والتفاعل (Use Case & Behavior):
تتيح للأطباء الجدد الذين سجلوا عبر **Google Sign-In** أو تخطوا إدخال الكود في شاشة التسجيل إدخال كود زميلهم في أي وقت من:
- شاشة اختيار الباقة (`PlansComparisonScreen`).
- شاشة إعدادات المالك (`OwnerSettingsScreen`).

```
┌────────────────────────────────────────────────────────┐
│  🎁 هل تمت دعوتك من قِبل طبيب زميل؟                    │
│  أدخل كود الدعوة للاستفادة من المكافأة                 │
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 🎟️ DOC-7X9AB (يتم جلبه تلقائياً من الحافظة)     │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  [        تخطي        ]    [       تفعيل الكود       ] │
└────────────────────────────────────────────────────────┘
```

- **الفحص التلقائي للحافظة (Smart Clipboard Detection):** فور فتح النافذة، تفحص الحافظة بنمط `DOC-XXXXX` وتضع الكود تلقائياً لتوفير عناء الكتابة على الطبيب.

## 3. مشاركة كود الدعوة ورابط التطبيق المباشر (`Referral Share Flow`)

في كارت كود الدعوة (`ReferralCodeCard`):
1. **زر [نسخ الكود]:** ينسخ الكود المجرد (`DOC-7X9AB`).
2. **زر [مشاركة نص الدعوة ورابط التطبيق]:** ينسخ رسالة جاهزة وذكية للمشاركة عبر WhatsApp/SMS:
   > *"مرحباً دكتور، أدعوك لتجربة تطبيق Clinic Pro لإدارة العيادات الطبية الذكية. استخدم كود الدعوة الخاص بي (DOC-7X9AB) عند التسجيل للحصول على مكافأة وخصومات ترحيبية!*  
   > *رابط التطبيق: https://play.google.com/store/apps/details?id=com.clinicpro.app"*
