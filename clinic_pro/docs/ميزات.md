## security 
 - Server-side security  (triggers , RLS , functions, pg_cron)
  RLS ex : owner can not add subscription if the status not equal "pending" , and can not update subscription table
  triggers ex : when owner add clinic , server check if subscription clinics usage is full . if it is full , will prevent adding new clinic and retun error  
  pg_cron ex : run function every day at 12 am to check and update subscription status (if the subscription is expired.)


 -  (Two-Layered Feature Gate): server-side + client-side
